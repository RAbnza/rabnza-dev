## A previous introduction

The original React portfolio brought together project cards, background information, and personal interests. It remains a visual record of the previous presentation rather than the source of current employment or education claims.

## What changed

This portfolio shifts the emphasis toward project evidence: real interfaces, implementation decisions, and the boundary between application capabilities and personal contributions. TindaTrack receives a full case study, while supporting work has room for context beyond a project modal.

The current site uses static Astro pages, self-hosted typography, and scoped Anime.js enhancements. Native scrolling and a complete reduced-motion layout keep the content usable without the cinematic layer.

## Looking back

The earlier site is useful as design history. Its student and internship wording has been superseded by the current graduate positioning. Historical profile claims should not be treated as current résumé information.
